# Vassole-Smart-Player-IPTV
Vassole Smart Player IPTV  Player de IPTV, gratuito e sem ativação. Reproduz listas M3U e contas Xtream Codes que o usuário cadastra. Não inclui, vende nem indica canais ou conteúdo. O Vassole Smart Player IPTV é um reprodutor de mídia. O usuário é responsável por ter direito de acesso às fontes que cadastrar.
